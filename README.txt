KEBUN RAYA CITRUS - LANDING PAGE

Isi project:
- index.html: struktur website dan konten
- style.css: seluruh styling, responsivitas, dan animasi
- script.js: menu mobile, animasi scroll, dan tautan WhatsApp

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder ini di VS Code.
3. Jalankan index.html di browser atau gunakan ekstensi Live Server.
4. Buka script.js dan ganti nomor WhatsApp contoh pada WHATSAPP_NUMBER.
   Gunakan format kode negara tanpa tanda +, spasi, atau tanda hubung.
5. Ganti nama contoh, teks, foto, alamat, dan area pengiriman dengan data toko sebenarnya.

Catatan:
- Foto memakai URL Unsplash, sehingga perlu koneksi internet.
- Produk difokuskan pada satu produk utama: jeruk peras.
- Pastikan klaim usaha dan detail produk sesuai kondisi nyata.
- Website ini adalah landing page statis; belum ada database, dashboard admin, atau checkout online.
